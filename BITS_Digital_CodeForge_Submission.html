Marks file format guidance

The uploaded Excel file should contain exactly three columns: BITS ID, Course, and Total Marks.

Total Marks must be numeric and on a 0–100 scale. Fractional values are rounded to the nearest integer.

Students receiving an NC grade should not be included.
